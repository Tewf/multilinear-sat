# Literature

`review.md` surveys the continuous-relaxation line for SAT (FourierSAT, GradSAT, FastFourierSAT), the discrete baselines this repo benchmarks against, the theorems that bound the method, and how this repo positions itself. `references.bib` has one BibTeX entry per work cited there.

Produced by condensing six internal reviews and the prototype benchmark written on 2026-08-26 (unpublished working notes), then independently re-verifying the FastFourierSAT and FourierSAT GitHub repos and about twenty citations against DBLP, arXiv and Crossref on 2026-08-27/28.
